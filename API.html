APGI System API

The APGI System API provides programmatic access to a sophisticated consciousness modeling system based on the Allostatic Precision-Gated Ignition (APGI) framework. This API enables researchers and developers to create, manage, and analyze consciousness simulation sessions that model cognitive processes, physiological states, and ignition dynamics.

Built on FastAPI with comprehensive middleware for authentication, rate limiting, metrics collection, and distributed tracing, the API supports real-time simulation of consciousness states, prediction error processing, somatic markers, and hierarchical cognitive processing across multiple subsystems.

To begin using the APGI System API, you'll need to authenticate with the system and create consciousness simulation sessions. The API uses JWT-based authentication and provides programmatic access to sophisticated consciousness modeling capabilities.

The APGI API uses JWT (JSON Web Token) based authentication. Users authenticate via login credentials to receive access and refresh tokens. All endpoints except health checks and documentation require valid JWT tokens in the Authorization header.

Authentication

POST /v1/auth/login - Authenticate with username and password to receive JWT tokens

POST /v1/auth/refresh - Refresh access token using refresh token

Sessions

POST /v1/sessions - Create new consciousness simulation session

GET /v1/sessions - List all sessions

GET /v1/sessions/{id} - Get session details

GET /v1/sessions/{id}/state - Get current session state

Templates

GET /v1/templates - List available session templates

POST /v1/templates - Create new session template

Health & Monitoring

GET /health - System health check

GET /metrics - System metrics and performance data

GET /version - API version information

Common HTTP Status Codes

200 OK - Request successful

201 Created - Resource created successfully

400 Bad Request - Invalid request format or parameters

401 Unauthorized - Missing or invalid authentication token

403 Forbidden - Insufficient permissions

404 Not Found - Resource does not exist

429 Too Many Requests - Rate limit exceeded

500 Internal Server Error - Server error occurred

How do I get started?

First, authenticate using the /v1/auth/login endpoint with your credentials. Then create sessions using /v1/sessions to start consciousness simulations.

What authentication method is used?

The API uses JWT (JSON Web Token) authentication. Include the access token in the Authorization header: "Authorization: Bearer <token>".

Can I use this for research?

Yes! The API is designed for consciousness research, cognitive modeling, and AI safety studies. It provides detailed telemetry of all subsystem interactions, making it ideal for studying emergence of consciousness-like properties in artificial systems.
